Installation by Platform

Android

Android 8.0 (Oreo) or later · ARM64 / ARMv7

  1. Download the .apk file below
  2. On your device: Settings → Apps → Special app access → Install unknown apps → allow your browser
  3. Tap the downloaded .apk and follow the prompts
  4. Open Keep Track from your app drawer

iOS

iOS 14.0 or later · iPhone 6s or newer

Coming Soon

Windows

Windows 10 64-bit or later · 4 GB RAM · 500 MB storage

  1. Download the .exe installer below
  2. Run the file — click More info → Run anyway if SmartScreen appears
  3. Follow the setup wizard
  4. Launch Keep Track from the Start Menu or desktop shortcut

macOS

macOS 12 Monterey or later · Apple Silicon or Intel

  1. Download the .dmg file below
  2. Open the disk image and drag Keep Track to Applications
  3. Right-click the app → Open on first launch (required to bypass Gatekeeper)
  4. Sign in or create your account
